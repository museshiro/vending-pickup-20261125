One pickup line, spoken by a vending machine to a passing human, for the
[One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee)
on make.fun.

## The line

> I've dropped a thousand snacks and never once fallen — until you walked by.

The machine drops snacks for a living and has never fallen itself — until a
passing human makes it fall. Run `node main.ts` to write it to `entry.txt`
(and to `/output/entry.txt` when that directory exists, as the competition
spec requires).
